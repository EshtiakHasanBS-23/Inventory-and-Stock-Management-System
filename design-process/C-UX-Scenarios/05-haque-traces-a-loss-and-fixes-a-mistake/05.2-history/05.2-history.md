## Overview

**Purpose:** The permanent stock record, newest first: who changed what, when, why, by how much, its value and the balance after. Filters live in the address so a view can be shared or bookmarked. Owners and Managers ask for a reversal from here.
**User situation:** Haque followed "Missing in counts" here, then looks for a double-entered sale.
**Entry:** Menu "History"; Dashboard loss rows (`?reason=…`); "History" chip on a product row (`?productId=…`).
**Exit:** Stays; after asking for a reversal, the request waits in Approvals.

## Layout

- **Desktop:** heading; a filter grid (Product, Reason, By, From, To); "Download CSV"; "Clear filters" when any filter is set; reversal panel (when open); the movement table; "Load more".
- **Phone:** filters wrap to one or two per row; the table keeps its columns and scrolls sideways inside its frame.

## States

|---|---|

| Load failed | "Couldn't load this. Refresh the page to try again." |
| No movements (or none match) | Clock icon + "No stock movements yet." (`history-table-empty`) |
| Reversal panel open | Panel above the table |
| Reversal sent | Panel closes; sent message |

## Refusal Messages (reversal, shown under "Why should it be reversed?")

| Trigger | Message |
|---|---|
| Reason empty | "Say why it should be reversed." |
| Already has a waiting or approved reversal | "This movement already has a reversal, asked for or approved." |
| A stock count | "A stock count cannot be reversed. Count the product again." |
| Damage-flag or reversal movement | "This movement cannot be reversed." |
| Role below Manager (API) | "Only an owner or manager can ask for a reversal." |

## Accessibility

- The "Reverse…" button's accessible name says what it reverses, so a screen-reader list of buttons is not a column of identical "Reverse…" entries.
- The empty actions header has a visually hidden "Actions" label. Change direction is sign + icon + colour.
- Filters are labelled selects and date inputs.

## API

| Call | When |
|---|---|
| `GET /api/v1/stock/movements?productId&reason&userId&from&to&limit=50&offset` | Load and "Load more" (`from` inclusive, `to` exclusive, as day starts) |
| `GET /api/v1/users/names` | People for the "By" filter |
| `GET /api/v1/stock/movements/export.csv?…` | `stock-history.csv`: Date (Dhaka time), SKU, Product, Direction, Reason, Quantity, Unit, Balance after, Value (BDT), By, Note; up to 10,000 rows |
| `POST /api/v1/approvals/reversals` `{movementId, note}` | Ask for reversal (201) |

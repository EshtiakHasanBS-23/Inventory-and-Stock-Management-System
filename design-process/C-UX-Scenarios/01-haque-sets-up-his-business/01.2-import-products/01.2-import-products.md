## Overview

**Purpose:** Create many products at once, with their opening stock, from an Excel sheet saved as CSV. Every row is checked in the browser first; the server checks again and creates all rows or none.
**User situation:** Haque has his product list in Excel and does not want to type 60 products.
**Entry:** "Import from Excel" button on Products (`products-import-link`).
**Exit:** "See products" link in the success message → `/products`.

## Layout

- **Desktop:** shared frame. Heading, a numbered list of three steps, then a white panel with the file picker, the problems box or the preview table, and the Import button.
- **Phone:** same order, full width. The preview table scrolls sideways inside its frame.

## What the reader accepts

- Header names are loose: case, spaces, underscores, brackets, "৳", "BDT" and "taka" are ignored, so "Unit cost (৳)", "unit_cost" and "UNITCOST" all mean unit cost.
- Comma or semicolon separators (semicolon when the first line has semicolons and no commas); quoted cells; UTF-8 BOM removed.
- Excel-style numbers such as "1,250.50" or "৳ 100".
- At most 1,000 rows. Row numbers in messages are spreadsheet rows (header is row 1).

## States

| State | What shows |
|---|---|
| No file | Steps and file picker only |
| File with problems | Problems box, no preview, no Import button |
| File ready | Ready line, preview, Import button |
| Importing | Button spinner |
| Done | Done message; file picker cleared |
| Server refused | Server message under the panel; preview stays so the person can see what was sent |

## Validation and Refusal Messages

**In the browser (`csvImport.ts`, `packages/contracts/src/importReport.ts`, `stock.ts`):**

| Trigger | Message |
|---|---|
| Empty file | "The file is empty." |
| Required column missing | "Missing column: <names>. Use the template." |
| Header only | "The file has no product rows." |
| More than 1,000 rows | "Import at most 1000 products at a time." |
| Bad SKU | "Row R: Enter a SKU of up to 40 characters." |
| Bad name | "Row R: Enter a product name." |
| Bad unit | "Row R: Enter a unit, such as pcs or ctn." |
| Bad minimum stock | "Row R: Enter a whole number, 0 or more." |
| Bad unit cost | "Row R: Enter a cost in taka, 0 or more, with up to 2 decimals." |
| Bad opening stock | "Row R: Enter a whole number, 0 or more." |
| SKU twice in the file | "Row R: SKU <sku> is also on row E." |

**From the server (nothing is created):**

| Trigger | Message |
|---|---|
| SKU already in the business | "Row R: a product with SKU <sku> already exists." |
| SKU twice in the file | "Row R: SKU <sku> is also on row E." |
| No rows or more than 1,000 | "The file has no product rows, or more than 1000." |

## Accessibility

- The file input has a visible label. The problems box and server error use `role="alert"`; the done message uses `role="status"`.
- Preview table has column headers with `scope="col"`; numbers are right-aligned.

## API

| Call | When | Result |
|---|---|---|
| `POST /api/v1/products/import` `{rows: [{sku, name, unit, unitCost, minStock, openingStock}]}` | Import button | 201 `{created, openingUnits}`; one transaction; each opening quantity above 0 becomes an "Opening stock" movement under the importer's name |

## Overview

**Purpose:** See every product with what is in stock and what it is worth; find one by name or SKU; add or correct products.
**User situation:** After the import, Haque checks the list and fixes one unit cost.
**Entry:** Menu "Products"; "See products" after an import; "Add products first." link on Stock in / out and Stock count when there are no products.
**Exit:** Row actions to Stock in / out, Flag damage, History; "Import from Excel"; "Download CSV".

## Layout

- **Desktop:** page header (title, subtitle, actions on the right); the add / edit panel (three-column form grid); toolbar with search and count; product table.
- **Tablet (700–1023 px):** form grid in two columns; bottom tab bar.
- **Phone (below 700 px):** form in one column; the table becomes one card per product: name and SKU as the card title, then "In stock", "Min stock", "Unit cost", "Value", "Status" each with its label, then the action chips.

## States

| State | What shows |
|---|---|
| Loading | "Loading…" |
| Load failed | "Couldn't load this. Refresh the page to try again." |
| No products | Box icon + "No products yet." (`products-empty`) |
| Search with no match | Box icon + "No products match this search." |
| Saved | Form resets to "Add a product"; list refreshes (also Dashboard and History caches) |
| Save failed | Message under the field the server named, or "Couldn't save. Try again." in the summary |

## Accessibility

- Status uses tint, icon and word, never colour alone.
- On phone cards each value keeps its label (`data-label`), so the meaning survives without the header row.
- The empty Actions column header has a visually hidden "Actions" label.

## API

| Call | When |
|---|---|
| `GET /api/v1/products` or `?q=<text>` | Load and search |
| `POST /api/v1/products` `{sku, name, unit, minStock, unitCost}` | Add (201) |
| `PATCH /api/v1/products/:id` `{name, unit, minStock, unitCost}` | Edit |
| `GET /api/v1/products/export.csv` | Download CSV `products.csv`: SKU, Name, Unit, In stock, Minimum stock, Status, Unit cost (BDT), Stock value (BDT) |

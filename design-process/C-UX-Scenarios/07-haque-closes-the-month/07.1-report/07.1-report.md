## Overview

**Purpose:** A stock report for a date range: per product, the quantity at the start, what came in, was sold, was damaged, was found missing or extra in counts, was adjusted, and the quantity at the end, with taka values at the cost of the time. Summary tiles and a CSV download.
**User situation:** Haque closes November and sends the figures to his accountant.
**Entry:** Menu "Report". Without dates in the address it shows this month: the 1st to today.
**Exit:** Stays; "Download CSV".

## Layout

- **Desktop:** heading; From / To date inputs; three summary tiles; "Download CSV"; the report table with a Total footer row.
- **Phone:** date inputs and tiles wrap; the table keeps its eight columns and scrolls sideways inside its frame.

## CSV Downloads (all three pages)

All CSVs start with a UTF-8 BOM so Excel opens them correctly, and any cell starting with `=`, `+`, `-` or `@` (or a tab or carriage return) gets a leading apostrophe so it is never run as a formula.

| From | File | Columns |
|---|---|---|
| Report | `stock-report.csv` | SKU, Product, Unit, Opening, Received, Sold, Damaged, Count difference, Adjusted, Closing, Received value (BDT), Sold value (BDT), Damaged value (BDT), Missing value (BDT); plus a total line |
| Products (01.3) | `products.csv` | SKU, Name, Unit, In stock, Minimum stock, Status, Unit cost (BDT), Stock value (BDT) |
| History (05.2) | `stock-history.csv` | Date (Dhaka time), SKU, Product, Direction, Reason, Quantity, Unit, Balance after, Value (BDT), By, Note; current filters; up to 10,000 rows |

The download is a plain link; the session cookie authorises it.

## Validation and Refusal Messages (API)

| Trigger | Message |
|---|---|
| Missing or bad start date | "Enter a valid start date." |
| Missing or bad end date | "Enter a valid end date." |
| End before start | "The end date must be on or after the start date." |

The page checks the range itself first and shows "Choose a start date on or before the end date." without calling the server.

## Accessibility

- Summary tiles are a description list (label + value).
- Table: column headers `scope="col"`, product names as row headers `scope="row"`, numbers right-aligned; signs use a true minus.
